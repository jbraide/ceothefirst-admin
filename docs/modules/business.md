# Business Module

The Business module manages the core identity and financial profile of the business.

## Functional Logic

### 🏢 Multi-tenant Profiles
All data in the system (Inventory, Transactions, etc.) is linked to the `id` of the Business profile currently logged in.

### 🛎️ Bookkeeping Reminders & Notifications
NairaFlow helps business owners stay consistent by sending a daily push notification reminding them to "Close the Books" (record any remaining sales/expenses).

- **`reminderTime`**: A string in **24-hour HH:mm format** (e.g., `"20:30"` for 8:30 PM). 
  - The backend uses this value to schedule a cron job specific to the user's timezone.
- **`fcmToken`**: The Firebase Cloud Messaging token generated by the mobile app. 
  - **Frontend Responsibility:** The app should send the current `fcmToken` to the `PATCH /business/profile` endpoint whenever the token is refreshed or upon user login. This ensures the backend always has a valid target for notifications.
- **Trigger Logic:** Every day at the `reminderTime`, the server adds a job to the notification queue. If the `fcmToken` is present and valid, the user receives a "Don't forget to record your sales for today!" alert.

### 🏢 Business Information Collection
NairaFlow is designed to be self-contained. The backend simply stores the business details provided by the owner. No external verification (e.g., bank API or CAC) is performed during the MVP.

- **Manual Entry:** The owner provides their Business Name, Address, Category (e.g., Retail, Food, Services), and Bank Details.
- **Purpose:** These details are used exclusively for:
  - Branding receipts and invoices.
  - Setting up the dashboard context.
  - Providing payment instructions on formal invoices.

### 🛡️ Access Control (RBAC)
- **Profile Updates:** Only the Business **Owner** can update the business profile.
- **Reminder Configuration:** Only the Business **Owner** can change the global reminder time.

## API Reference

> **Business Type:** The `businessType` field can be set to `"product"`, `"service"`, or `"both"`. This helps the frontend customize the UI (e.g., hiding inventory for service-only businesses).

### Get Profile
`GET /business/profile`

**Response Example:**
```json
{
  "success": true,
  "data": {
    "id": "cmny6omdf000...",
    "ownerPhone": "08000000001",
    "name": "NairaFlow Store",
    "email": "store@example.com",
    "category": "Retail",
    "businessType": "product",
    "state": "Lagos",
    "city": "Ikeja",
    "bankName": "GTBank",
    "accountNumber": "0123456789",
    "reminderTime": "21:00",
    "fcmToken": "...",
    "createdAt": "2026-04-14T05:31:20.260Z"
  }
}
```

### Update Profile
`PATCH /business/profile`

**Example Request:**
```json
{
  "name": "NairaFlow Store",
  "email": "hello@nairaflow.com",
  "category": "Retail",
  "state": "Lagos",
  "city": "Lekki",
  "address": "123 Main St, Lagos",
  "reminderTime": "21:00",
  "fcmToken": "fcm_token_from_mobile_device"
}
```

**Response Example:**
```json
{
  "success": true,
  "data": {
    "id": "cmny6omdf000...",
    "name": "NairaFlow Store",
    "reminderTime": "21:00"
  }
}
```
### Update Reminder Time
`PATCH /business/reminder-time`

**Request:**
```json
{ "reminderTime": "19:30" }
```

### Validate Bank Account
`POST /business/bank/validate`
Resolves a 10-digit NUBAN account number to an account name using a bank code.

**Request:**
```json
{ "bankCode": "058", "accountNumber": "0123456789" }
```

**Response:**
```json
{
  "bankCode": "058",
  "accountNumber": "0123456789",
  "accountName": "CHUKWUMA OKAFOR"
}
```
