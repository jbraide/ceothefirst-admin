# Debts Module

The Debts module tracks money owed to the business (Receivables) and money the business owes (Payables). 

## Functional Logic

### 📈 Creation via Transactions
You do not typically create a Debt record directly. Instead, they are generated by the **Transactions Module**:
- **Receivable:** Created when a **Sale** (`/transactions/sell`) is recorded with `paymentMethod: 'credit'`.
- **Payable:** Created when a **Purchase** (`/transactions/buy`) is recorded with `paymentMethod: 'credit'`.

The `contactId` (optional) or `contactName` provided in the transaction request identifies the debtor/creditor.

### 💳 Repayment Logic (`POST /debts/:id/pay`)
When a user records a repayment:
1. **Debt Closure:** The `paidAmount` on the debt record is incremented. If it reaches or exceeds the `totalAmount`, the status changes from `OPEN` to `CLOSED`.
2. **Cash Book Integration:** A new `Transaction` of type `debt_repayment` is automatically generated and linked to the debt (`transactionId`). This ensures the cash flow reports accurately reflect the money received or paid.

## API Reference

### List Debts
`GET /debts`
- Query parameters: `type` (`receivable`|`payable`), `contactId` (string), `page` (default: 1), `limit` (default: 20).
- Only `OPEN` debts are returned by default.

**Response Example:**
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "id": "cmny6rrcp00...",
        "type": "receivable",
        "contactId": "cmny7...",
        "contactName": "Debt Test Customer",
        "totalAmount": "1200",
        "paidAmount": "500",
        "status": "OPEN",
        "transactionId": "cmny6rrcj...",
        "createdAt": "2026-04-14T05:31:26.541Z"
      }
    ],
    "meta": { "total": 1, "page": 1, "limit": 20, "pages": 1 }
  }
}
```

### Debt Summary
`GET /debts/summary`

### Get Single Debt
`GET /debts/:id`

### Record Repayment
`POST /debts/:id/pay`
